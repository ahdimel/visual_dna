# visual_dna

Sun, March 23, 2025
Welcome to my short and sweet project to visualize a human genome from a .vcf input file.

## Security audit (2026-10-23)

Dependencies were checked against [OSV.dev](https://osv.dev); nothing malicious was found.
Packages with known vulnerabilities were upgraded (Pillow 13, Streamlit 1.66.1, Tornado, urllib3,
GitPython, certifi and others), an unused stray package (`smc-python`) was removed, and
`requirements.txt` was regenerated.
